# Консольная библиотека книг

## Что умеет
- загружать библиотеку из файла, бэкапа или создавать с нуля
- выводить все книги по убыванию страниц
- искать книги по автору
- искать книги по названию
- добавлять книгу с проверкой на существование такой книги
- удалять книгу из библиотеки
- сохранять в файл и в бэкап
- выводить статистику авторов по написанным книгам
- при закрытии программы спрашивать о сохранении если были внесены изменения

## Как запустить
dotnet run --project ConsoleApp3

## Автотесты
- тест на добавление одинаковой книги
- тест на добавление книг с одинаковыми названиями но разными авторами
- тест на проверку данных добавляемой книги
- тест на корректное добавление книги без ошибок
- тест на то что копия не меняет оригинал библиотеки 
- тест на корректный вывод статистики по авторам
- тест на корректную загрузку библиотеки и ее сохранение с бэкапом
- тест на загрузку испорченного файла и создание его копии
